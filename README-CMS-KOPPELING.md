# PDN website v5 - CMS-koppeling fase 1

Deze versie houdt de bestaande layout intact, maar haalt menu, nieuws, galerij en dynamische pagina's op uit `pdn-api`.

## Nodig
Upload eerst `api/worker.js` uit deze ZIP naar `pdn-api` en voer `/setup` uit.
Daarna upload je de inhoud van `website/` naar GitHub `pdn-website-v5`.

## Testen
- Homepage: laatste nieuws komt uit CMS.
- Menu: komt uit CMS.
- Clubnieuws: komt uit CMS.
- Fotogalerij: komt uit Media/R2.
- Dynamische pagina: `page.html?slug=over-ons`.
